# Expiry Alert App

A React + Firebase web application for tracking product expiry in a store/inventory setting. Includes dashboards, analytics, SMS alerts, donation tracking, and more.

## Features
- Product and inventory tracking with expiry dates
- Dashboard with analytics
- SMS alerts for expiring products
- Donation management for near-expiry items
- Clearance/offers section for expiring stock
- Voice assistant integration

## Tech Stack
- React (frontend)
- Firebase (backend/cloud functions, database)

## How to Run
1. Clone this repository
2. Run `npm install` to install dependencies
3. Run `npm start` to start the development server
